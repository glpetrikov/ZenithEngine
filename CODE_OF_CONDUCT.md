# Code of Conduct

## Our pledge

We want Zenith Engine to be a place where people can ask questions, report bugs, and contribute code without being harassed or belittled. Everyone is welcome regardless of age, experience level, background, identity, or nationality.

## Expected behavior

- Be respectful and assume good faith.
- Give and accept criticism of code and ideas, not of people.
- Be patient with beginners. Everyone started somewhere.
- Stay on topic in issues and pull requests.
- Write in whatever language you are comfortable with. English is preferred for issues and PRs so that others can follow, but nobody will be mocked for mistakes or accent.

## Unacceptable behavior

- Harassment, insults, personal attacks, or discriminatory language
- Trolling, deliberate derailing, or spam
- Publishing someone else's private information
- Sexualized language or attention directed at others
- Pressure on maintainers or contributors (for example, demanding features or fixes, or repeatedly pinging for reviews)
- Anything else that would be reasonably considered inappropriate in a professional setting

## Scope

This applies to all project spaces: issues, pull requests, discussions, and any other channel run by the project. It also applies when someone represents the project in public.

## Enforcement

Reports go to the project maintainer, Gleb Petrikov, at `glpetrikov@gmail.com`. All reports are handled privately and the reporter's identity is kept confidential. For problems in a specific issue or pull request, you can also use GitHub's "Report content" option.

The maintainer may respond with any of the following, depending on severity, using the tools GitHub provides:

- A warning and a request to stop, either in the thread or privately
- Editing, hiding, or deleting comments, and locking or closing issues and pull requests
- Temporarily limiting interactions with the repository, or blocking the person from it
- Reporting the account to GitHub Support, for serious or repeated violations

The maintainer's decision is final.
